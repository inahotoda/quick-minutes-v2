# INAHO 議事録アプリ ご利用ガイド

> 会議を録音するだけで、AIが自動で議事録を作成します。

---

## はじめに（初回のみ）

### 1. アプリにアクセス

お知らせしたURLにアクセスしてください。

- **推奨ブラウザ**: Google Chrome
- iPhone / iPad の場合は **Safari** または **Chrome** をご利用ください

### 2. Googleアカウントでログイン

「Googleでログイン」ボタンをタップし、会社のGoogleアカウントでログインしてください。

### 3. Google Driveのアクセス権を設定

初回ログイン時に共有ドライブへのアクセス権が必要です。画面の案内に従って「アクセス権をリクエスト」してください。管理者の承認後に利用可能になります。

## iPhoneでのセットアップ

### ホーム画面にショートカットを追加する

すぐにアプリを起動できるよう、ホーム画面にショートカットを追加しましょう。

**手順（Safariの場合）:**

1. Safariでアプリを開く
2. 画面下の **共有ボタン（□↑）** をタップ
3. **「ホーム画面に追加」** を選択
4. 名前を「議事録」などに設定
5. **「Webアプリとして開く」は必ずOFFにする**
6. 「追加」をタップ

> **重要: 「Webアプリとして開く」は必ずOFFにしてください。**
> ONにすると（PWAモード）、他のアプリに切り替えた際に録音が停止してしまいます。
> OFFにしておけば、通常のブラウザとして開くため、バックグラウンドでも録音が継続します。

## iPhoneご利用時の注意点

### 電話着信で録音が一時停止します

iPhoneで録音中に電話がかかってくると、**録音が自動的に一時停止**します。

- 電話を終了した後、アプリに戻ってください
- 画面上の **「再開」ボタン** を手動でタップして録音を再開してください
- 再開を忘れると、電話後の会話が録音されませんのでご注意ください

### その他の注意点

- 録音中はなるべく **アプリの画面を開いたまま** にしてください
- 長時間の会議では、iPhoneの **自動ロック（スリープ）を「なし」に設定** しておくと安心です
  - 設定 → 画面表示と明るさ → 自動ロック → 「なし」

## Macでのセットアップ

### Chromeでアプリとして登録する

1. Google Chromeでアプリにアクセス
2. 右上の「⋮」メニュー → 「保存して共有」 → 「ショートカットを作成」
3. 「ウィンドウとして開く」にチェックを入れて作成
4. Dockに表示されたアイコンを右クリック → 「オプション」 → 「Dockに残す」

> Macの場合はPWAモードでも問題なく録音できます。

## 基本的な使い方

### STEP 1: 会議モードを選ぶ

| モード | 用途 | 特徴 |
|--------|------|------|
| **社内** | 社内ミーティング | 決定事項・アクションアイテム重視 |
| **商談** | お客様との商談 | 顧客要望・次回アクション重視 |
| **その他** | 汎用的な会議 | バランスの取れた構成 |

### STEP 2: 参加者を確認する

- 事前登録されたメンバーからチェックボックスで選択
- その場で新規追加も可能

> **会議プリセット**: よく開催する会議の設定（モード・参加者・時間）を事前に保存しておけます。定例会議はプリセットからワンタップで開始できます。

### STEP 3: 録音を開始する

1. **マイクボタン** をタップ
2. 録音時間を選択（30分 / 60分 / 無制限）
3. 「Mtgスタート」をタップ

録音中は画面にタイマーが表示されます。設定時間が近づくとアラームで通知されます。

### STEP 4: 録音を終了する

**停止ボタン** をタップすると、AIが自動で議事録を生成します（1〜2分程度）。

### STEP 5: 議事録を確認・保存する

1. 生成された議事録を確認し、必要に応じて編集
2. 「ドライブに保存」をタップしてGoogle Driveに保存

> 保存ボタンは **1回だけ** 押してください。保存が完了するとボタンが「保存済み」に変わります。

## 会議用マイクの利用（推奨）

会議室で複数人が参加する場合は、**会議用マイク**（Anker PowerConf S3など）の利用を推奨します。

```
     Mac / iPhone
          │ USB-C または Bluetooth
     ┌────┴────┐
     │  マイク  │ ← テーブルの中央に設置
     └─────────┘
       👥👥👥
     参加者（5〜6人）
```

## メンバーの音声登録

AIが「誰が何を話したか」を自動判別できるよう、各メンバーの声のサンプルを登録しておくと精度が上がります。

**登録手順:**

1. 画面右上の「設定」をタップ
2. 「メンバー管理」へ進む
3. 「新しいメンバーを追加」をタップ
4. 10秒程度、名前や自己紹介を話して音声を録音
5. 名前が自動認識されるので、確認して保存

> 静かな場所で、はっきりと話してください。

---

## ファイルアップロードでの議事録生成

録音以外にも、既存のファイルから議事録を生成できます。

**対応ファイル:**
- 音声ファイル（MP3, WAV, M4A など）
- PDF・画像（会議資料として参考情報に利用）
- テキスト（文字起こし済みのテキスト）

## トラブルシューティング

### 議事録生成が失敗した場合

1. エラー発生時に「音声ダウンロード」の確認が表示されます
2. 「はい」をタップして音声ファイルをデバイスに保存
3. ネットワーク復旧後、「ファイルアップロード」から再度生成

> 録音データはエラー時にダウンロードできるので、会議の録音が消えることはありません。

### Google Drive保存が失敗した場合

1. 「コピー」ボタンで議事録をクリップボードにコピー（バックアップ）
2. ログアウトして再ログイン
3. もう一度「ドライブに保存」をタップ

### ログインできない場合

- 会社のGoogleアカウントを使用しているか確認してください
- ブラウザのキャッシュをクリアしてお試しください
- それでも解決しない場合は管理者にお問い合わせください
